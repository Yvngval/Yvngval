## Captain's Profile

- Master 2 student (DCI) at Université Paris Cité, sailing toward applied AI and data science.
- My devil fruit: turning raw datasets into models that can explain their own decisions.
- I measure before I trust: every voyage comes with benchmarks, baselines and honest metrics.

## Log Pose

- Explainable machine learning (SHAP, interpretable baselines, PR-AUC over accuracy)
- Information retrieval and semantic search (BM25, dense embeddings, rank fusion)
- Vector search and approximate nearest neighbors (HNSW, IVF-PQ, LSH)
- Data privacy: anonymization and the attacks that try to break it
- RAG assistants and full-stack applications around AI
